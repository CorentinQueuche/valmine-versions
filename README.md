# Les Failles de Valmine : versions pour Windows

Ce dépôt ne contient que les installateurs du jeu pour Windows (le code du jeu est ailleurs).

## Installer

1. Ouvrir la dernière version dans [Releases](../../releases/latest).
2. Télécharger `Les-Failles-de-Valmine-<version>-installation.exe` et le lancer.
3. L'installateur n'est pas signé : Windows SmartScreen peut avertir au premier lancement. Cliquer sur
   « Informations complémentaires », puis « Exécuter quand même ».

## Mises à jour

Une fois installé, le jeu se met à jour tout seul : il cherche une nouvelle version au lancement, la télécharge en fond
(seulement ce qui a changé) et l'installe à la fermeture, ou tout de suite depuis l'écran titre.

Les parties restent sur l'ordinateur et sont aussi recopiées dans `Documents\Mes jeux\Les Failles de Valmine\Parties`.

Les anciennes versions doivent rester publiées : elles servent à ne télécharger que les différences.
